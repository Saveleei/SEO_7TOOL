# Stalex feed preview

- Исполнитель: Codex
- Ветка: `codex/stalex-feed-preview`
- Базовый commit: `767d83ea2dd3057e75d5d3cd95a94062906443ae`
- Цель: подготовить безопасный, непубликующий адаптер двух XML-выгрузок Stalex, который сопоставляет товары с текущей логикой каталога 7TOOL и формирует отчёт предварительного просмотра.
- Область: скрипты импорта/нормализации, конфигурация сопоставления категорий, регрессионные тесты и документация. Витрина, production, Beget, cron, секреты и база данных не изменяются.
- Критерий готовности: импорт выполняется только в preview-режиме; неизвестные категории, некорректные связи, цена, остаток, гарантия и чужие контакты блокируются или явно отражаются в отчёте; существующие тесты проходят.
- План проверок: узкие тесты адаптера, `npm run lint`, `npm test`, `npm run build` при изменениях production-кода.
- Commit SHA: будет добавлен после завершения.
- Ограничения: автоматическая публикация и использование данных Stalex допускаются только после письменного подтверждения коммерческих условий, гарантий и прав на контент.
- Коммерческое правило владельца: для всех товаров Stalex применяется гарантия 12 месяцев; исходное значение фида сохраняется только в аудите и не меняет публичный срок.
