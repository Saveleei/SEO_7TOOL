- Цель: локальное рабочее место менеджера для просмотра заявки, фильтрации очереди, назначения ответственного, смены этапа, заметок и контроля времени первого ответа.
- Архитектурное ограничение: контур работает только при `QUOTE_TEST_MODE=1`; никаких email/MAX/CRM отправок, production-базы, секретов или деплоя.
- Критерий готовности: append-only история событий, валидируемые переходы статусов, detail view заявки, очередь с полезными фильтрами, desktop/mobile браузерная проверка, узкие и полные проверки, build.
- Статус: готово и проверено.

## Реализовано

- Очередь заявок со сводкой и фильтрами: все, новые, требуют реакции, готовим КП, отправлены.
- Детальная карточка заявки: точные позиции, количество и цена на момент запроса, требования клиента, комментарий, контакты, реквизиты, источник и UTM.
- Назначение Евгения Савельева, контролируемые соседние переходы `Получена → Проверка → КП готово → Отправлено`, возврат на предыдущий рабочий этап и внутренние заметки.
- Append-only `events.jsonl`: действия не перезаписывают исходный `requests.jsonl`; idempotency UUID хранится только как SHA-256.
- SLA первого содержательного действия: безопасный дефолт 30 минут, настройка `QUOTE_FIRST_RESPONSE_MINUTES`; простое назначение менеджера не считается началом обработки.
- Same-origin, размер запроса, rate limit, test-mode gate и серверная валидация для manager action API.
- Клиентская мобильная панель КП скрыта только в рабочем месте менеджера, чтобы не перекрывать действия.

## Ограничения следующего production-этапа

- JSONL, in-memory rate limit и отсутствие авторизации допустимы только для локального прототипа. До production нужны БД, роли/авторизация, объектное хранилище, распределённый rate limit, CSRF-сессия и outbox.
- Форма клиента не собирает Telegram/MAX покупателя, поэтому менеджерское рабочее место честно предлагает только телефон и email; автоматическая отправка не выполняется.
- У текущего `vinext` остаётся базовое сообщение RSC-prefetch для части старых `Next Link`. Критические переходы нового рабочего места выполняются обычной навигацией и проверены отдельно.
