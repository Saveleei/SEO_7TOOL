## Цель

Развивать новую самостоятельную концепцию B2B-магазина 7TOOL на базе тестового storefront, не смешивая её с интерфейсом и доработками действующей версии сайта.

## Область владения

- `design-exploration/staging-pilot/**`;
- `ai-handoffs/storefront-concept-v2-20260911.md`.

Production-приложение `7tool-source/**` в эту задачу не входит. Ветка `codex/availability-manager` и её изменения не переносятся.

## Критерии следующего этапа

- единая новая концепция главной, каталога, категории и карточки товара;
- короткие пути: поиск модели, подбор по задаче, отправка спецификации, запрос КП;
- честные статусы цены и наличия без выдуманных складских данных;
- контакты менеджера: телефон, email, Telegram и MAX;
- адаптивная desktop/mobile-версия;
- тестовые формы не отправляют данные во внешние системы;
- публикация и production-интеграция только после отдельного подтверждения пользователя.

## Проверка базы

- `pnpm run lint` — успешно;
- `pnpm run build` — успешно, собрано шесть маршрутов;
- исходная ветка `codex/staging-conversion-pilot` после фиксации чистая.

## Реализованный проход

- категория перестроена по приоритету `товары → расширенный инженерный подбор`;
- в первом экране категории появились количество моделей, доступность и быстрый переход к подбору;
- мобильный контакт менеджера сокращён до четырёх доступных каналов без тяжёлой карточки;
- мобильные фильтры по умолчанию свёрнуты, чтобы быстрее показать товары;
- карточка товара получила компактный buybox: наличие, цена с НДС, количество и КП находятся рядом;
- на мобильной карточке закреплена товарная панель с ценой и запросом КП;
- добавлены коммерческие микрогарантии рядом с CTA;
- добавлена фирменная social-preview обложка и отдельное изображение товара для metadata карточки.

## Проверки прохода

- ESLint всего тестового storefront — успешно;
- production build — успешно, шесть маршрутов;
- HTTP: все шесть маршрутов и `/og.png` возвращают `200`;
- mobile `390×844`: горизонтальное переполнение отсутствует;
- точный поиск `STEYR-35` показывает карточку нужной модели;

- «Добавить в заявку» сохраняет товар только в локальном тестовом состоянии, внешней отправки нет;
- формы не отправлялись.
