# Handoff: conversion visuals

- Агент: Codex
- Ветка: `codex/conversion-visuals`
- Цель: подготовить три эстетичных и конверсионно безопасных визуальных направления для 7TOOL с учётом финального бренд-кита и текущей B2B-логики продажи промышленного оборудования.
- Область владения: `design-exploration/conversion-visuals/**` и этот handoff.
- Production-код: не изменялся.

## Реализовано

- Industrial Clarity — базовый коммерческий вариант.
- Engineering Commerce — параметрический инженерный вариант.
- Premium Industrial — премиальный вариант для дорогих и проектных категорий.
- Официальные primary/inverse SVG и диагональный элемент скопированы из бренд-кита без модификации.
- Для каждой концепции созданы desktop, mobile full-page и mobile first-fold скриншоты.

## Проверки

- Browser QA: 320, 390, 768, 1280, 1440, 1600, 1920 px.
- Горизонтальный overflow: 0 px на всех проверенных вариантах.
- Broken images: 0.
- Console errors: 0.
- Primary CTA в mobile 390×844 заканчивается на 597 px / 618 px / 542 px соответственно.
- Поиск видим на всех проверенных ширинах.
