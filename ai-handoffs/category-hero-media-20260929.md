# Category hero media

- Исполнитель: Codex
- Ветка: `codex/category-hero-media`
- Базовый commit: `d096869`
- Область: `design-exploration/staging-pilot`
- Цель: усилить первый экран категорий реальным управляемым изображением без потери короткого пути к выбору товара.
- Критерии готовности:
  - изображение помогает распознать категорию и не заменяет заголовок, подкатегории или CTA;
  - используется только подтверждённое изображение из текущего каталога/редакторского слоя;
  - `object-fit: contain`, стабильный aspect-ratio, без обрезки и layout shift;
  - отсутствие изображения не создаёт пустой или сломанный блок;
  - desktop и mobile сохраняют видимые пути «выбрать тип» и «подобрать по задаче»;
  - решение покрыто тестами и проходит lint, полный test и build.
- Исходные ограничения реализации: без изменений production/Beget/DNS/cron/секретов и без внешних отправок. После явного согласия пользователя разрешён отдельный deploy только на `test.7tool.ru`.
- Реализовано:
  - верхний блок всех страниц `/catalog/category/:slug` получил отдельное изображение категории без обрезки;
  - для выбранного вида/семейства используется изображение реального товара из текущей выборки;
  - для шести ключевых категорий ручная фотография из `/test/settings/homepage` имеет приоритет над обычным изображением фида;
  - остальные категории используют собственное feed-backed изображение подкатегории;
  - при ошибке загрузки сохраняется стабильная фирменная заглушка, без layout shift;
  - на mobile порядок остаётся конверсионным: смысл → подбор → изображение;
  - подпись в административном редакторе объясняет, что фото используется и на главной, и в категории.
