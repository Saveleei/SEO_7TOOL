# All category details — 2026-09-22

- Исполнитель: Codex.
- Ветка: `codex/all-category-details`.
- База: `88f18ec` (`codex/drilling-subcategory-details`).
- Цель: распространить проверенную иерархию и конверсионные сценарии сверлильных станков на все фактические категории каталога.
- Область: `design-exploration/staging-pilot`; production, DNS, секреты, фид и внешние каналы не изменяются.

## Критерий готовности

- Каждая категория получает корректную структуру подкатегорий/типов на основе фактического фида.
- Для каждого типа выбран честный сценарий: фильтры, подбор по задаче или инженерная заявка.
- Тексты, приоритетные параметры и подписи карточек учитывают специфику оборудования.
- Навигация и параметры URL сохраняют выбранную категорию и тип.
- Ключевые категории проверены на desktop и mobile, тесты и production build проходят.

## Проверки

- Добавлен единый слой `categoryAssortmentTaxonomy.mjs`: типы товаров определяются по фактическим названиям, вариантам, брендам и значениям параметров фида; у каждой категории есть безопасная fallback-группа.
- Категории без прежней структурной навигации получили 2+ понятных входа в ассортимент, профиль выбора, подсказки «Подходит для / Сначала проверить / Сравнивать по» и собственный сценарий подбора.
- Семейство сохраняется параметром `family` в URL, фасетах, формах фильтра, активных чипах и контексте карточек. Товар не теряется и не попадает одновременно в несколько семейств.
- Для инженерно сложных групп используется открытая форма подбора по задаче; для стандартных расходников и серийных товаров — управляемый подбор и фильтры.
- Устранена ошибка активного состояния: на обзорной странице больше не подсвечивается первый раздел из-за сравнения `undefined`.
- Регрессия `tests/category-assortment-taxonomy.test.mjs`: все опубликованные категории имеют минимум два пути выбора; каждый товар классифицируется ровно один раз; суммы групп совпадают с ассортиментом; подписи карточек и URL проверены.
- Узкий тест новой матрицы: `4/4` успешно.
- Полный `npm test`: `221/221` успешно.
- Полный `npm run lint`: успешно.
- Production `npm run build`: успешно.
- Browser QA без отправки форм: desktop — компрессоры, кромкорезы для труб, заточные станки, ленточнопильные станки и станочная оснастка; mobile `390×844` — винтовые компрессоры. Горизонтального переполнения не обнаружено.
