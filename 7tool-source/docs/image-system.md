# Image system

The canonical implementation is documented in [Image Intelligence](./image-intelligence.md). Only locally processed assets with a current approved rights grant and explicit public-use permissions may appear in content.

PHASE 21 expert photos follow the same ownership principle: the profile stores a local `/media/` or `/uploads/` path and an immutable human-reviewed rights reference. Remote photographs, research-only images, removed watermarks and third-party assets represented as owned are prohibited.

Public expert profiles do not expose the identity-evidence or rights-evidence reference. They expose only the approved local image and profile fields.
