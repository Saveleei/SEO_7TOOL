# Content quality system

The content-quality contract spans three guarded stages:

1. [Content Platform](./content-platform.md) requires an approved brief, verified claim sources, FACT/SEO/EXPERT approvals, safe media and a human final transition.
2. [Score-driven scaling](./scale-governance.md) requires `QualityScore >= 85`, `EvidenceScore >= 80`, `DifferentiationScore >= 60` and no hard fail.
3. [Content Refresh](./content-refresh.md) rechecks semantic duplication, cannibalization, performance decay and a real expert profile before subsequent publication decisions.

Quality score never overrides a hard fail. Invented technical data, duplicate intent, severe cannibalization, copyright problems, broken canonicals, misleading claims, duplicate articles and missing unique value block publication independently.

External content may inform topics and aggregate user problems. It may not be copied, lightly rewritten or published with third-party imagery presented as owned.
