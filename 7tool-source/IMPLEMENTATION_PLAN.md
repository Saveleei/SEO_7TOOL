## Контрольные точки

- До миграций: определить production-пути и сделать копии БД/uploads.
- После изменения фида: тестировать только на копии XML/SQLite.
- После реализации: `npm ci`, `npm run lint`, `npm run build`, автоматические тесты.
- Перед production: проверить реальные cron/PM2 на Beget; не менять их по предположению.
- После переключения: главная, девять категорий, подкатегории, товары, корзина, заявки, админка, медиа, sitemap, robots, canonical, JSON-LD, SSL и логи.
