# Как выбрать корончатое сверло — редакционный пакет

Статус: `AWAITING_HUMAN_BRIEF_REVIEW`. Материал подготовлен, но намеренно не опубликован и не помечен как проверенный человеком.

Технический эксперт: **Евгений Савельев**. Статус экспертной проверки: `PENDING_CONTENT_APPROVAL` — имя назначено, но одобрение содержания ещё не зафиксировано.

## Что входит

- `draft.json` — метаданные, Wordstat-семантика, реестр источников, ArticleBrief, структурированный `ARTICLE_BLOCKS_V1`, FAQ, перелинковка и редакционный gate.
- Автоматическая проверка выполняется через существующий prohibited-content scanner и дополнительную проверку источников, метаданных и состояния публикации.

## Проверка

```bash
npm run seo:content:draft:check -- --input=editorial-drafts/kak-vybrat-koronchatoe-sverlo/draft.json
```

Полный набор тестов также проверяет этот пакет:

```bash
npm test
```

## Что требуется перед переносом в production Content Platform

1. Подтвердить, что статья отвечает на информационный интент «как выбрать» и не дублирует коммерческую категорию `/c/koronchatye-sverla`.
2. Зарегистрировать и проверить источники с правом `PUBLISHABLE_FACTS`; каждый источник пока имеет состояние `PENDING_HUMAN_REVIEW`.
3. Сопоставить `requiredProductSlugs` с текущими ID недрафтовых товаров из категории `koronchatye-sverla`.
4. Утвердить ArticleBrief человеком до сохранения первой immutable revision.
5. Получить и зафиксировать содержательное одобрение технического эксперта Евгения Савельева. Автор материала — «Редакция 7TOOL».
6. Подтвердить собственное/лицензированное изображение или оформить human-reviewed no-match.
7. Выполнить FACT, SEO, EXPERT и FINAL approval в штатном CLI. Только после этого допустимы `PUBLISHED + INDEX` и добавление URL в sitemap.

Цены, остатки и число товаров не зафиксированы в тексте: они продолжают выводиться из актуального товарного фида.
