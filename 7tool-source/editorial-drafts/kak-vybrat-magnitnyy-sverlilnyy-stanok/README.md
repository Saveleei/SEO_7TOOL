# Редакционный пакет: выбор магнитного сверлильного станка

Статья закрывает отдельный информационно-коммерческий интент выбора и не заменяет категорию `/c/stanki-sverlilnye/magnitnye`, которой принадлежат широкие запросы «купить».

Семантика собрана в Wordstat по России и проверена по выдаче Google. Технические утверждения ограничены официальными материалами Hougen, BDS, Promotech и актуальным товарным фидом 7TOOL. Фото взяты из разрешённых материалов поставщика с сохранённым водяным знаком; происхождение и контрольные суммы записаны в `media-manifest.json`.

Публикация выполняется только при совпадении контрольных сумм `draft.json` и `media-manifest.json` с человеческим разрешением в `approval.json`.
