# Контент-план 7TOOL.ru

Дата: 18 августа 2026 года. 60 тем построены на реальном опубликованном каталоге. Это редакционный backlog, а не разрешение на автоматическую публикацию. Для каждой темы сначала нужны фактический спрос, SERP/intention review, экспертная проверка технических утверждений и решение cannibalization guard. Предлагаемый будущий namespace: `/knowledge/`; до реализации маршрута URL не создавать.

Обозначения: TOFU — знакомство с задачей; MOFU — выбор решения; BOFU — выбор товара/поставщика. «Товары по facts» означает динамический блок из товаров с подтверждёнными характеристиками, без догадок по названию.

1. Подтвердить query concept реальными данными Вордстата/Search Console/Вебмастера и проверить intent в выдаче.
2. Проверить, нет ли существующей страницы с тем же нормализованным интентом.
3. Получить источники facts: feed, паспорт/руководство производителя, технический специалист 7TOOL. Не переносить характеристики между моделями.
4. Подготовить структуру ответа, 2–4 полезные внутренние ссылки и блок товаров только по подтверждённым фильтрам.
5. Проверить title/H1/canonical/schema, доступность без JavaScript и отсутствие неподтверждённых преимуществ.
6. После публикации измерять не только трафик, но и переходы в категории, product views, заявки, звонки и запросы КП.
