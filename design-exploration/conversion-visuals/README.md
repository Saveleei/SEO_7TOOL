# 7TOOL — три конверсионных визуальных направления

Три адаптивных, кодовых прототипа на основе финального бренд-кита 7TOOL. Это изолированное дизайн-исследование: production-код, маршруты, аналитика и формы сайта не изменялись.

## Концепции

1. [Industrial Clarity](01-clarity/index.html) — основной кандидат для всего сайта. Белый коммерческий интерфейс, быстрый поиск, чёткая товарная иерархия, один главный CTA.
2. [Engineering Commerce](02-engineering/index.html) — лучший сценарий для технических категорий. Подбор от параметров задачи, фильтры на языке инженера, сравнение моделей.
3. [Premium Industrial](03-premium/index.html) — сильнее всего работает для дорогого и проектного оборудования. Контролируемый тёмный hero, премиальная подача, но цена, наличие и поиск остаются видимыми.

## Рекомендованный микс

- 60% Industrial Clarity — каркас, header, поиск, карточки, формы и мобильная логика.
- 30% Engineering Commerce — фильтры, подбор, сравнение и технические данные.
- 10% Premium Industrial — hero и проектные посадочные для дорогого оборудования.

## Что защищает конверсию

- поиск по модели, артикулу и типу оборудования виден сразу;
- цена, НДС, наличие и срок не прячутся за декоративной подачей;
- один оранжевый фокусный CTA на каждый экран/состояние;
- запрос КП требует только телефона, уточнения переносятся в разговор;
- зелёный используется только для наличия, оранжевый — для действия;
- все три mobile hero показывают H1 и первичное действие в первом экране 390×844;
- официальный логотип используется как SVG из бренд-кита;
- основной оранжевый `#FF5A00` получает чёрный текст, а белый текст используется на `#D24600`.

## Проверено

- ширины 320, 390, 768, 1280, 1440, 1600 и 1920 px;
- горизонтальный overflow: 0 px;
- сломанные изображения: 0;
- console errors: 0;
- поисковое поле остаётся доступным на всех проверенных ширинах.

## Ограничение

Числа и обещания в прототипах взяты из текущего контекста 7TOOL и используются для реалистичной композиции. Перед production-внедрением любые SLA, остатки, гарантийные сроки и количественные claims нужно подтвердить данными бизнеса.
