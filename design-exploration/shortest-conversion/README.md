# 7TOOL Search to Order

Итоговый адаптивный прототип главной страницы с кратчайшими путями к конверсии.

## Три пользовательских сценария

1. Пользователь знает модель или артикул: вводит запрос, получает точное совпадение с ценой, наличием и кнопкой корзины прямо в поисковой подсказке.
2. Пользователь знает задачу: выбирает операцию и один ключевой параметр, затем переходит в уже отфильтрованный каталог.
3. Закупщик имеет спецификацию: передаёт список позиций без последовательного поиска каждой из них.

## Источники решений

- Baymard: поддержка exact search по модели, SKU и вторичным данным товара.
- Grainger: единый поиск по keyword, item, model и part number; отдельный bulk-order путь.
- McMaster-Carr: поиск как главный интерфейс каталога и навигация через понятные производственные семейства.
- RS Components: поиск по keyword, manufacturer part number и внутреннему номеру.
- MISUMI: поиск по part number и конфигурируемый технический подбор.

## Conversion guardrails

- поиск доступен в header на всех размерах;
- на desktop усиленная поисковая строка повторяется в hero;
- на mobile дублирующая строка скрывается, поэтому первый экран не перегружен;
- точное совпадение не отправляет пользователя в общий список;
- CTA зависит от состояния: корзина для товара с ценой, подбор для задачи, КП для списка;
- основной `#FF5A00` используется с чёрным текстом; `#D24600` с белым — только на тёмном фоне;
- форма КП не требует длинной анкеты на первом шаге.

## Проверка

- адаптивность: 320, 390, 768, 801, 820, 840, 900, 1120, 1280, 1440, 1600 и 1920 px;
- horizontal overflow: 0 на всех проверенных ширинах;
- broken images: 0;
- console errors: 0;
- проверены: exact-match, добавление в корзину, смена задачи и выбор диаметра;
- эталонные состояния сохранены в `screenshots/`.
